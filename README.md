SQL_Project_Music_Store_Analysis

Overview:

This project consists of SQL queries designed to analyze a music store database. The queries are categorized into three difficulty levels: Easy, Moderate, and Advanced. Each query addresses specific business questions related to employees, customers, invoices, sales trends, and artist popularity.

Dataset Used :
The project is based on a relational database containing the following tables:
employee
invoice
customer
invoice_line
track
album
artist
genre


Techniques Used :
SQL Joins: Used extensively to connect multiple tables.
Aggregations: SUM, COUNT, and AVG functions for data analysis.
Window Functions: ROW_NUMBER() for ranking data.
Common Table Expressions (CTEs): Simplifies complex queries.
Recursive Queries: Used to retrieve hierarchical data.
Subqueries: Fetching results based on nested queries.
